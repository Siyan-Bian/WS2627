# 地理学引用文献指南阅读笔记

来源：[Zitationsleitfaden 2025/26](./Zitationsleitfaden_2025-26.pdf)，LMU 地理学系，2025/26 冬季学期，全文 13 页。以下页码均对应 PDF 页码。

**核心思路：正文用短引标明观点来源，文末用完整条目帮助读者找到原文；两者必须对应，全文格式必须一致。** 本指南是该系的写作指引，其中的具体约定应结合课程要求使用。

## 一 基本原则

引用的目的，是使研究过程与依据可以被他人追溯、检验和批评。（第 1–2 页）

- 具体的论断、研究发现和事实需要来源支持，改写他人观点也需要引用。
- 地理学通常采用 Harvard 作者年份制：`(Müller 2009, 12)`，即作者姓氏、年份、页码。
- 正文引用过的来源全部收入参考文献表；未引用的文献不列入。
- 指南允许不同标点和排版形式，但选定后应全文统一。

## 二 正文如何引用

### 三种引用方式

| 方式 | 使用方法 | 格式示意 |
| --- | --- | --- |
| 直接引用 | 只有原话本身重要时才逐字引用；加双引号，短引放在句末标点之前 | `„原文内容“ (Müller 2009, 12).` |
| 间接引用 | 用自己的语言转述，仍标注来源 | `转述内容 (Müller 2003, 15).` 或 `Müller (2003, 15) 指出……` |
| 二手引用 | 仅在例外情况下使用，以 `zit. nach` 标出转引关系 | `(Maier 1965, 14; zit. nach Müller 2001, 12)` |

二手引用示例表示：Maier 是原始来源，实际转引自 Müller。直接引用应节制，长引文可缩进。（第 2–4 页）

### 常见情况速查

| 情况 | 处理方式 |
| --- | --- |
| 两位作者 | 如 `(Müller & Maier 2009, 15)`；也允许用逗号或 `und`，需统一 |
| 三位及以上作者 | 正文用首位作者加 `et al.`；文献表仍列出全部作者 |
| 同姓的不同作者 | 加名字首字母，如 `(Müller, S. 2002, 12)` |
| 同一作者同一年多篇作品 | 用 `2009a`、`2009b` 等区分，正文与文献表保持对应 |
| 同一句有多个来源 | 放在同一括号内，以分号分隔 |
| 引用范围为连续两页 | `12f.` 表示第 12 页及下一页 |
| 引用范围超过两页 | `12ff.` 表示第 12 页及后续多页 |
| 紧接着再次引用同一来源 | 可用 `ebd.`；页码变更时写成 `(ebd., 19)`，自然地理不使用这种写法 |

缺少信息时，先认真核查原文，再使用：`o.V.` 无作者、`o.O.` 无出版地、`o.J.` 无年份、`o.S.` 无页码。（第 5–6、8–9 页）

### 直接引文中的改动

- 省略一个或多个词用 `[…]`，省略单个字母用 `[.]`。
- 原文中的错误或特殊拼写可在相应位置后标注 `[sic]`、`[sic!]` 或 `[!]`。
- 自行补充说明用 `Anm. d. Verf.`；自行加粗或斜体强调用 `Herv. d. Verf.`，原文强调应保留。
- 自译内容注明 `Übers. d. Verf.`。按本指南，英语直接引文保留原文，其他语言的引文应翻译，并优先采用间接引用。（第 3–4 页）

## 三 特殊来源与图表

### 网络来源

正文通常写作者或责任机构与年份，如 `(Destatis 2010)`；若引用的 PDF 有页码，还需加页码。完整 URL 和访问日期放入文献表。（第 6、11–12 页）

**先判断文献类型，再选择格式。** 从 ScienceDirect 等平台下载的期刊论文，仍按期刊论文著录，不能仅因从网上获取就写成普通网页。本指南明确要求学术写作避免使用 Wikipedia，并审慎评价网络来源。

### 论文集中的章节

引用具体章节时，正文写**章节作者**，文献表再列出章节及论文集编者信息。只有引文无法归属到具体章节时，才把论文集整体作为来源。（第 7、10 页）

### 图片 表格与地图

- 从其他作品引用的图、表、地图均须注明来源，并在正文中解释或指引，如 `siehe Abb. 1`。
- 原样使用：`(Goudie 1994, 30)`；修改后使用：`(verändert nach Goudie 1994, 30)`。
- 根据他人数据自行作图，仍须标出数据来源，如 `Datenquelle: DWD, 2013`。
- 自制图和自拍照在人文地理中通常分别注明 `eigene Darstellung`、`eigene Aufnahme, 日期`；自然地理通常不加此类标记。（第 7–8 页）

## 四 参考文献表如何编排

### 排序与作者信息

1. 所有来源合并排列，按作者或编者姓氏的字母顺序排序，不按书籍、期刊、网站分类。
2. 同一作者的独著先于合著；同一作者或编者的多部作品按年份排列，同年作品用小写字母区分。
3. 同一作品内部的作者顺序照原出版物保留，不能重新按字母排序。
4. 列出全部作者或编者，名字通常缩写；不写学术头衔。编者用 `Hrsg.` 标明。（第 8–10 页）

### 常见类型模板

以下统一使用“姓氏, 名字首字母”的形式；出版地或出版社的选择见下一节。

| 类型 | 完整条目结构 |
| --- | --- |
| 专著 | `作者 (年份): 书名. 出版地或出版社.` |
| 论文集章节 | `章节作者 (年份): 章节标题. In: 编者 (Hrsg.): 论文集名. 出版地或出版社, 章节起止页码.` |
| 系列丛书 | `作者或编者 (年份): 书名 (= 丛书名及卷号). 出版地或出版社.`；编者须加 `Hrsg.` |
| 期刊论文 | `作者 (年份): 文章标题. 期刊名, 卷号(期号), 起止页码.` |
| 地图 | `作者或编者 (年份): 地图名. 出版地, 比例尺 1:X.`；编者须加 `Hrsg.` |
| 报纸文章 | `作者 (年份): 文章标题. In: 报纸名, 年卷, 期号, 出版日期, 页码.` |
| 网页 | `作者或责任机构 (年份): 页面标题. URL: 完整网址 (Stand: 访问日期).`；机构作为编者时加 `Hrsg.` |

机构名称只有在使用通行的官方缩写时才可直接缩写；否则首次引用须写出全称。纸质提交时，按指南要求不显示超链接样式，文献表仍保留网址文字。（第 9–12 页）

## 五 自然地理与人文地理的差异

| 项目 | 自然地理 Physische Geographie | 人文地理 Humangeographie |
| --- | --- | --- |
| 间接引用中的 `vgl.` | 不常用 | 指南允许使用 |
| 连续重复引用中的 `ebd.` | 不使用 | 可按连续引用规则使用 |
| 图的来源位置 | 指南未规定统一位置 | 通常置于图下 |
| 自制图或自拍照标记 | 通常不写 | 通常标出自制或自拍及相应信息 |
| 专著出版信息 | 通常写出版社；用首个出版地时，该地应能明确对应唯一出版社 | 通常写出版地 |

依据第 4、6–7、9 页。上表保留指南对两类地理学写作习惯的区别。

- [ ] 作者、年份、页码及同年字母标记一致。
- [ ] 文献表列全作者，保留原作者顺序，并按规定排序。
- [ ] 论文集章节引用章节作者，在线期刊论文按期刊格式著录。
- [ ] 网页包含完整网址和访问日期，自制图注明所用外部数据。
- [ ] 全文引用格式统一，并符合所写自然地理或人文地理课程的约定。
