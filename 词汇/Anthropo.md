# 旅游地理

| 单词 | 中文 | 解释 | 词形与用法 |
| --- | --- | --- | --- |
| der Tourismus | 旅游 | 讲义定义包括离开惯常环境、一定动机和临时停留，连续停留不超过一年。 | 通常无复数 |
| die Tourismusgeographie | 旅游地理学 | 研究旅游活动的空间分布、互动及其经济、社会文化和生态影响。 | 通常无复数 |
| die Anthropogeographie | 人文地理学 | 关注人类活动及其与空间的关系；旅游地理属于其研究领域。 | 通常无复数 |
| die Humangeographie | 人文地理学 | 关注人类活动及其与空间的关系；旅游地理属于其研究领域。 | 通常无复数 |
| die Wirtschaftsgeographie | 经济地理学 | 研究经济活动的空间组织；与旅游地理密切相关。 | 通常无复数 |
| der Ortswechsel | 空间位移 | 人离开原所在地点，是界定旅游的基本要素之一。 | 复数：Ortswechsel |
| die gewohnte Umgebung | 惯常环境 | 日常生活所熟悉的活动环境；旅游通常发生在其外。 | 复数：Umgebungen |
| der Aufenthalt | 停留 | 在某地逗留；旅游定义强调临时性。 | 复数：Aufenthalte |
| das Motiv | 动机 | 解释为什么出行，如休闲、商务或健康。 | 复数：Motive |
| der Geschäftsreisetourismus | 商务旅游 | 因商务目的出行，讲义将其置于旅游边缘领域。 | 通常无复数 |
| der Gesundheitstourismus | 健康旅游 | 为健康相关目的出行，讲义将其置于旅游边缘领域。 | 通常无复数 |
| der Erholungstourismus | 休闲疗养旅游 | 以休息和恢复身心为目的，属于讲义的旅游核心领域。 | 通常无复数 |
| der touristische Aktivitätsraum | 旅游活动空间 | 旅游者及相关主体开展活动的空间，是旅游地理的核心研究对象。 | 复数：Aktivitätsräume |
| die Aggregationsebene | 汇总层级 | 将个体或区域信息汇总的层次，如地方、国家和国际层级。 | 复数：Aggregationsebenen |
| das Verbreitungsmuster | 分布格局 | 某类旅游现象在空间中的排列和分布。 | 复数：Verbreitungsmuster |
| das Interaktionsmuster | 互动格局 | 旅游主体或地区之间联系与相互作用的空间模式。 | 复数：Interaktionsmuster |
| der Akteur | 行动主体 | 参与旅游活动或影响旅游发展的个人、企业、机构等。 | 复数：Akteure |
| interdisziplinär | 跨学科的 | 不同学科协作研究共同问题。 | 形容词 |
| transdisziplinär | 超学科的 | 超越单一学科框架整合知识；学习解释也包括研究与实践的结合。 | 形容词 |
| der Reiseverkehrsstrom | 旅游流 | 从客源地向目的地移动的人员流。 | 复数：Reiseverkehrsströme |
| das Quellgebiet | 客源地 | 旅游流出发的地区；与目的地相对。 | 复数：Quellgebiete |
| das Zielgebiet | 目的地区 | 旅游流到达的地区。 | 复数：Zielgebiete |
| der Binnenreiseverkehr | 国内旅游流 | 本国居民在本国境内旅行。 | 通常无复数 |
| der Binnenverkehr | 国内旅游流 | 本国居民在本国境内旅行。 | 通常无复数 |
| der Einreiseverkehr | 入境旅游流 | 居住在国外的人进入所考察国家旅行。 | 通常无复数 |
| der Ausreiseverkehr | 出境旅游流 | 本国居民到国外旅行。 | 通常无复数 |
| der Inlandstourismus | 境内旅游 | 以发生地为准，等于国内旅游流加上入境旅游流。 | 通常无复数 |
| der nationale Tourismus | 国民旅游 | 以居民归属为准，等于国内旅游流加上出境旅游流。 | 通常无复数 |
| der internationale Tourismus | 国际旅游 | 等于入境旅游流加上出境旅游流。 | 通常无复数 |
| die Ankunft | 到访人次 | 统计到达次数；不能直接当成互不重复的旅游者人数。 | 复数：Ankünfte |
| das Reiseverhalten | 旅游行为 | 人们选择目的地、出行时间、交通和活动等的方式。 | 通常无复数 |
| das touristische Angebot | 旅游供给 | 目的地及企业提供的住宿、交通、活动等产品与服务。 | 复数：Angebote |
| die touristische Nachfrage | 旅游需求 | 旅游者对旅游产品和服务的需要及购买选择。 | 通常无复数 |
| die Destination | 旅游目的地 | 作为整体被旅游者选择和体验的地点或地区。 | 复数：Destinationen |
| das Beherbergungswesen | 住宿业 | 提供酒店等旅游住宿服务的行业。 | 无复数 |
| der Reiseveranstalter | 旅游产品组织商 | 组织组合旅游产品并将其推向市场的经营者。 | 复数：Reiseveranstalter |
| der Reisemittler | 旅游中介 | 在旅游者与服务供应方之间提供销售或预订服务。 | 复数：Reisemittler |
| der Dienstleister | 服务提供者 | 提供旅游相关服务的主体，如博物馆等。 | 复数：Dienstleister |
| die Segmentierung | 市场细分 | 按动机、行为或社会人口特征等划分旅游市场。 | 复数：Segmentierungen |
| die Wertschöpfung | 增加值创造 | 旅游活动带来的新增经济价值，不等同于出行距离或次数。 | 通常无复数 |
| der Ertrag | 收益 | 滑雪场经营模型中随开放天数等条件变化的经营成果。 | 复数：Erträge |
| die Gewinnschwelle | 盈亏平衡点 | 德语学习补充，对应讲义的 break even point；收入与成本相抵。 | 复数：Gewinnschwellen |
| der Klimawandel | 气候变化 | 气候长期变化；讲义关注其对雪况、旅游季和经营的影响。 | 通常无复数 |
| die Klimafolgenforschung | 气候影响研究 | 研究气候变化对自然、经济与社会活动的影响。 | 通常无复数 |
| die Schneesicherheit | 积雪可靠性 | 在所需时间内拥有足够雪量以开展滑雪活动的可靠程度。 | 无复数 |
| die Schneedecke | 积雪覆盖层 | 覆盖地面的雪层；不能只由是否下雪判断。 | 复数：Schneedecken |
| die Schneehöhe | 雪深 | 地面积雪的厚度，是雪况判断指标之一。 | 复数：Schneehöhen |
| die Beschneiung | 人工造雪 | 以技术手段改善雪况，同时增加水和电的需求。 | 复数：Beschneiungen |
| der Kunstschnee | 人造雪 | 人工造雪产生的雪。 | 通常无复数 |
| der optimale Skitag | 最佳滑雪日 | 讲义按雪况、气温、日照、风和日期类型等共同界定。 | 复数：optimale Skitage |
| der Öffnungstag | 营业日 | 滑雪场可开放经营的一天；不必然达到最佳滑雪日标准。 | 复数：Öffnungstage |
| die Anpassungskapazität | 适应能力 | 旅游主体调整目的地、时间或活动以应对变化的能力。 | 复数：Anpassungskapazitäten |
| die zeitliche Verlagerung | 时间转移 | 将旅行提早或推迟；与更换目的地不同。 | 复数：Verlagerungen |
| die räumliche Verlagerung | 空间转移 | 改变旅游目的地，如转往雪况更可靠的地区。 | 复数：Verlagerungen |
| die globale Erwärmung | 全球变暖 | 全球平均温度升高；讲义用不同升温情景比较滑雪风险。 | 通常无复数 |
| der ökologische Fußabdruck | 生态足迹 | 表示活动对资源及环境的压力；本讲例子涉及人工造雪。 | 复数：Fußabdrücke |
| die Nachhaltigkeit | 可持续性 | 在旅游中兼顾资源环境、社会和经济的长期承受能力。 | 无复数 |
| die Einstellung | 态度 | 人们对可持续旅游的评价或意愿，不等于实际行动。 | 复数：Einstellungen |
| das Verhalten | 行为 | 实际采取的旅游行动，如交通选择和是否进行碳补偿。 | 通常无复数 |
| die Einstellungs-Verhaltens-Lücke | 态度行为差距 | 德语学习译名；对应讲义 Attitude-Behaviour-Gap，指积极态度未转化为相应行动。 | 复数：Lücken |
| die CO₂-Kompensation | 碳补偿 | 通过支持减排等项目补偿排放的做法；区别于直接减少自身排放。 | 复数：Kompensationen |
| das Umweltzeichen | 环境标志 | 表示产品或服务满足特定环境要求的标识。 | 复数：Umweltzeichen |
| die Opportunitätskosten | 机会成本 | 选择某方案而放弃其他机会的代价，如额外时间或放弃偏好。 | 复数词 |
| die Zahlungsbereitschaft | 支付意愿 | 消费者愿意为某项旅游产品或属性支付的程度。 | 无复数 |
| der Anreiz | 激励 | 使可持续方案更有吸引力的安排。 | 复数：Anreize |
| ressourcenschonend | 节约资源的 | 尽量降低能源、水等资源消耗。 | 形容词 |
| umweltverträglich | 与环境相容的 | 使活动对环境的负面影响保持在可承受范围内。 | 形容词 |
| der Overtourism | 过度旅游 | 旅游压力对居民生活或目的地环境造成明显负面影响的现象。 | 无复数，英语借词 |

# 什么是科学

| 单词                             | 中文        | 解释                                  | 词形与用法                                           |
| ------------------------------ | --------- | ----------------------------------- | ----------------------------------------------- |
| die Wissenschaft               | 科学或学术研究   | 按照可讨论、可检验的方法和标准获取、整理并应用知识的活动。       | 复数：Wissenschaften                               |
| der Wissenschaftler            | 研究者       | 从事科学研究的人，其工作需要接受方法和同行讨论的检验。         | 复数：Wissenschaftler；阴性：die Wissenschaftlerin     |
| die Erkenntnis                 | 认识或研究发现   | 通过观察、思考和检验形成的理解，不等于未经审查的意见。         | 复数：Erkenntnisse                                 |
| der Erkenntnisgewinn           | 认识的获得     | 研究使人们对现象或关系形成新的理解。                  | 复数：Erkenntnisgewinne                            |
| der Erkenntnisfortschritt      | 认识进步      | 通过批评、检验和修正推进对问题的理解。                 | 复数：Erkenntnisfortschritte                       |
| der Begriff                    | 概念        | 词语所表达的意义或认识内容，需要与词语本身和指涉现象区分。       | 复数：Begriffe                                     |
| die Methode                    | 方法        | 为回答研究问题而采用的有规则、可说明的操作途径。            | 复数：Methoden                                     |
| die Aussage                    | 陈述或命题     | 可以讨论其内容、依据和适用范围的表述。                 | 复数：Aussagen                                     |
| die Gültigkeit                 | 有效性或适用性   | 陈述在何种条件和范围内成立，科学结论通常有边界。            | 通常无复数                                           |
| die Widerspruchsfreiheit       | 无矛盾性      | 陈述之间逻辑上不互相冲突；这一点本身不保证经验上为真。         | 通常无复数                                           |
| die Kritik                     | 批评或审查     | 质疑研究的前提、方法和结论，是讲义强调的认识进步动力。         | 此义通常无复数                                         |
| die Logik                      | 逻辑        | 研究推理形式与有效关系，不能单独替代经验检验。             | 此义通常无复数                                         |
| die Problemlösungsfähigkeit    | 问题解决能力    | 理论在理解和处理问题方面的能力，是讲义讨论的评价标准。         | 通常无复数                                           |
| wissenschaftlich               | 科学的或学术的   | 符合相应研究标准，并能说明其依据、方法与适用范围。           | 形容词                                             |
| widerspruchsfrei               | 无矛盾的      | 表述在逻辑上自洽，不等于事实判断必然正确。               | 形容词                                             |
| widerlegbar                    | 可反驳的      | 能够设想证据或论证使某陈述被否定。                   | 形容词                                             |
| beweisbar                      | 可证明的      | 能够在明确的前提、规则或证据标准下获得证明。              | 形容词                                             |
| verfahrensorientiert           | 注重程序的     | 按照明确方法和操作步骤推进研究。                    | 形容词                                             |
| nachvollziehbar                | 可理解并可追溯的  | 他人能够跟随研究步骤，理解结论如何形成。                | 形容词                                             |
| transparent                    | 透明的       | 清楚公开研究的前提、方法、资料和论证过程。               | 形容词                                             |
| wiederholbar                   | 可重复的      | 在说明的条件下能够再次开展研究或观测；讲义也提示需考虑具体研究情境。  | 形容词                                             |
| die Beschreibung               | 描述        | 说明观察到什么、在哪里及具有什么特征，区别于解释原因。         | 复数：Beschreibungen                               |
| die Erklärung                  | 解释        | 说明现象为什么发生，并提出现象间联系的机制或原因。           | 复数：Erklärungen                                  |
| die Theoriebildung             | 理论建构      | 把概念、关系和解释组织成有联系的理论体系。               | 复数：Theoriebildungen                             |
| die Gestaltung                 | 干预与塑造     | 运用知识选择行动并改变现实，同时考虑可能的后果。            | 复数：Gestaltungen                                 |
| die Wahrnehmung                | 知觉        | 人对感觉信息的组织和理解，受注意力、经验和解释框架影响。        | 复数：Wahrnehmungen                                |
| das Kippbild                   | 双稳态图像     | 同一图像可以被交替看成不同对象，讲义以年轻和年老妇人的图像为例。    | 复数：Kippbilder                                   |
| die multistabile Wahrnehmung   | 多稳态知觉     | 面对相同刺激时，知觉在多个可能解释之间切换。              | 通常无复数                                           |
| der visuelle Reiz              | 视觉刺激      | 进入视觉系统的信息，同一刺激可以引起不同解释。             | 复数：visuelle Reize                               |
| das Phänomen                   | 现象        | 被观察、描述或研究的事件、过程或事物表现。               | 复数：Phänomene                                    |
| die Kartierung                 | 制图调查      | 在实地或资料基础上记录现象的位置和分布。                | 复数：Kartierungen                                 |
| die Zählung                    | 计数        | 记录研究对象的数量，是讲义列举的观察方法之一。             | 复数：Zählungen                                    |
| die Befragung                  | 访谈或问卷调查   | 通过提问获取人的经验、判断或行为信息。                 | 复数：Befragungen                                  |

| subjektiv                      | 主体相关的     | 受到观察者经验、位置和理解方式的影响。                 | 形容词                                             |
| theorieabhängig                | 依赖理论的     | 观察时关注什么、如何分类和解释，受到理论前提影响。           | 形容词                                             |
| die doppelte Kontingenz        | 双重偶联性     | 互动双方都可采取不同选择，并根据对方的可能反应调整自身行动。      | 通常无复数                                           |
| die unaufmerksame Blindheit    | 无意视盲      | 注意力集中在特定任务时，没有意识到视野中其他明显对象。         | 通常无复数；英语：inattentional blindness                |
| die Aufmerksamkeit             | 注意力       | 对某些信息的集中处理，会影响哪些现象被察觉。              | 此义通常无复数                                         |
| das Begriffswort               | 概念词       | 承载或表达某个概念的词语，要与概念的意义区分。             | 复数：Begriffswörter                               |
| das Zeichen                    | 符号        | 代表或指涉某种意义或现象的表达形式，如文字。              | 复数：Zeichen                                      |
| der Interpretationsrahmen      | 解释框架      | 理解概念和现象时所依赖的背景、规则与学科语境。             | 复数：Interpretationsrahmen                        |
| die Polysemie                  | 多义性       | 同一词语具有多个相关含义，可能造成学术交流中的理解差异。        | 通常无复数                                           |
| das semiotische Dreieck        | 符号学三角     | 用符号、概念和现象之间的关系说明意义如何建立。             | 复数：semiotische Dreiecke                         |
| die Typologie                  | 类型体系      | 按若干特征组织概念或对象的分类框架。                  | 复数：Typologien                                   |
| der präskriptive Begriff       | 规定性概念     | 表达价值标准或应当如何的概念，如好、坏、公正。             | 复数：präskriptive Begriffe                        |
| der deskriptive Begriff        | 描述性概念     | 用于描述现实对象、特征或方面的概念。                  | 复数：deskriptive Begriffe                         |
| der operationale Begriff       | 操作性概念     | 与可直接经验或测量的属性相联系的概念。                 | 复数：operationale Begriffe                        |
| der theoretische Begriff       | 理论概念      | 描述抽象或复杂、无法直接观察的内容，需要通过其他概念连接经验。     | 复数：theoretische Begriffe                        |
| die Wirklichkeit               | 现实        | 研究试图观察、描述和解释的实际世界。                  | 此义通常无复数                                         |
| das Merkmal                    | 特征        | 用于描述、区分或分类对象的属性。                    | 复数：Merkmale                                     |

| das Werturteil                 | 价值判断      | 依据某种价值标准作出的评价，区别于单纯描述现实。            | 复数：Werturteile                                  |
