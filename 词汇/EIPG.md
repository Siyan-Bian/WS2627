# 地球系统

| 单词 | 中文 | 解释 | 词形与用法 |
| --- | --- | --- | --- |
| die Naturwissenschaft | 自然科学 | 用观察、测量和实验研究自然过程。 | 复数：Naturwissenschaften |
| die Messung | 测量 | 用可记录的数据检验问题或假设。 | 复数：Messungen |
| das Muster | 模式或格局 | 反复出现的规律性特征，也可指空间分布形式。 | 复数：Muster |
| die Hypothese | 假设 | 对现象提出的、可进一步检验的解释。 | 复数：Hypothesen |
| das Experiment | 实验 | 在控制条件下开展的检验。 | 复数：Experimente |
| die Theorie | 理论 | 将相关解释组织起来，并能用于产生可检验预测的框架。 | 复数：Theorien |
| das Naturgesetz | 自然定律 | 描述自然中稳定规律的表述；本讲强调测量检验。 | 复数：Naturgesetze |
| die Vorhersage | 预测 | 由解释或理论推导出的待检验结果。 | 复数：Vorhersagen |
| das Kausalitätsprinzip | 因果性原则 | 关注条件、原因与结果之间的因果联系。 | 复数：Kausalitätsprinzipien |
| das System | 系统 | 由彼此联系的部分组成、能与外部区分的整体。 | 复数：Systeme |
| das Erdsystem | 地球系统 | 将地球各组成部分及其相互作用作为整体理解。 | 复数：Erdsysteme |
| die Komponente | 组成部分 | 构成系统的部分，与 Element 在本讲中近义。 | 复数：Komponenten |
| das Kompartiment | 分室或储存单元 | 系统中容纳能量和物质的部分。 | 复数：Kompartimente |
| die Wechselwirkung | 相互作用 | 组成部分彼此影响，并可能相互改变。 | 复数：Wechselwirkungen |
| die Atmosphäre | 大气圈 | 包围地球的气体部分。 | 复数：Atmosphären |
| der Ozean | 大洋 | 地球主要的海水储存与运动空间。 | 复数：Ozeane |
| die Kryosphäre | 冰冻圈 | 地球系统中冰雪和冻结部分。 | 通常无复数 |
| die Anthroposphäre | 人类圈 | 人类活动及其塑造的环境部分。 | 通常无复数 |
| die Landoberfläche | 陆地表面 | 本讲将其与土壤、岩石和淡水一起列作地球系统组成。 | 复数：Landoberflächen |
| das Süßwasser | 淡水 | 含盐量较低的水，与海水区分。 | 无复数 |
| das offene System | 开放系统 | 与环境既交换能量，也交换物质。 | 复数：offene Systeme |
| das geschlossene System | 封闭系统 | 与环境交换能量，但不交换物质的理想系统。 | 复数：geschlossene Systeme |
| das abgeschlossene System | 孤立系统 | 与环境既不交换能量，也不交换物质。 | 复数：abgeschlossene Systeme |
| das isolierte System | 孤立系统 | 与环境既不交换能量，也不交换物质；与 abgeschlossenes System 同义。 | 复数：isolierte Systeme |
| der Energieaustausch | 能量交换 | 能量跨越系统边界的传递。 | 通常无复数 |
| der Stoffaustausch | 物质交换 | 物质跨越系统边界的传递。 | 通常无复数 |
| kontinuierlich | 连续的 | 强调连续的状态或变化。 | 形容词 |
| diskret | 离散的 | 强调可分开的状态或单元。 | 形容词 |
| deterministisch | 确定性的 | 按确定关系描述系统行为。 | 形容词 |
| probabilistisch | 概率性的 | 按概率描述系统行为。 | 形容词 |
| linear | 线性的 | 输入与输出满足线性关系。 | 形容词 |
| nicht-linear | 非线性的 | 输入与输出不满足线性关系，响应不一定成比例。 | 形容词 |
| der Fluss | 通量或流 | 在本节系统语境中指连接储存单元的物质或能量流，不只指河流。 | 复数：Flüsse |
| die Materie | 物质 | 系统中储存、转移的实体物质，与能量相区分。 | 无复数 |
| die Energieerhaltung | 能量守恒 | 能量能够转移和转化，但总量满足守恒。 | 无复数 |
| die Massenerhaltung | 质量守恒 | 计算系统收支时必须满足的质量约束。 | 无复数 |
| die Impulserhaltung | 动量守恒 | 描述运动与相互作用的物理约束之一。 | 无复数 |
| die Drehimpulserhaltung | 角动量守恒 | 与旋转运动相关的守恒关系。 | 无复数 |
| der Stoffwechsel | 新陈代谢 | 生物体内的物质与能量转化过程。 | 通常无复数 |
| die Reproduktion | 繁殖 | 生物产生后代、延续种群的过程。 | 复数：Reproduktionen |
| die Rückkopplung | 反馈 | 某变化产生的后果反过来影响原来的过程。 | 复数：Rückkopplungen |
| die Fernwirkung | 远距离影响 | 一个地区或组成部分的变化影响远处的系统部分。 | 复数：Fernwirkungen |
| der globale Wandel | 全球变化 | 跨越地球系统各部分的全球性环境变化，范围比气候变化更广。 | 无复数 |
| der Meeresspiegel | 海平面 | 海面的平均高度；可随气候与海洋变化而变化。 | 复数：Meeresspiegel |
| das Tiefdruckgebiet | 低压区 | 本讲指出其通常带来降水。 | 复数：Tiefdruckgebiete |
| das Hochdruckgebiet | 高压区 | 本讲指出其通常带来晴朗天气。 | 复数：Hochdruckgebiete |
| der Wasserdampf | 水蒸气 | 气态水，可通过凝结参与云的形成。 | 无复数 |
| dynamisch | 动态的 | 系统状态持续随时间变化。 | 形容词 |
| der Boden | 土壤 | 由矿物、水、溶解物质和空气等组成，是粮食生产的基础。 | 复数：Böden |
| das Gestein | 岩石 | 构成地壳的重要物质，不等同于已经形成的土壤。 | 复数：Gesteine |
| das Mineral | 矿物 | 构成岩石和土壤矿质部分的基本物质。 | 复数：Minerale / Mineralien |
| die gelöste Substanz | 溶解物质 | 以溶解状态存在于水中的物质。 | 复数：gelöste Substanzen |
| die Verwitterung | 风化 | 岩石或矿物在原地发生破碎、分解或改变；图中 Weathering 的德语。 | 通常无复数 |
| die Erosion | 侵蚀 | 土壤或岩石物质被剥离并搬运；区别于原地风化。 | 复数：Erosionen |
| der Ionenaustausch | 离子交换 | 溶液与土壤颗粒表面的离子相互交换；对应 Ion exchange。 | 通常无复数 |
| die Humifizierung | 腐殖化 | 有机残体转化为腐殖质的过程；对应 Humification。 | 通常无复数 |
| die Aggregation | 团聚作用 | 土壤颗粒聚集形成团聚体；对应 Aggregation。 | 复数：Aggregationen |
| die Stoffverlagerung | 物质迁移 | 物质在土壤剖面中移动；对应图中 Translocation。 | 复数：Stoffverlagerungen |
| das Kation | 阳离子 | 带正电的离子，如 Ca²⁺。 | 复数：Kationen |
| das Anion | 阴离子 | 带负电的离子，与阳离子相对。 | 复数：Anionen |
| der Humus | 腐殖质 | 土壤中的有机物质部分，表面电荷可影响离子吸附。 | 通常无复数 |
| der Ton | 黏土或黏土矿物 | 细粒土壤物质；本讲强调其胶体表面的电荷作用。 | 复数：Tone〔类型〕 |
| das Kolloid | 胶体 | 细小分散颗粒；土壤胶体表面可吸附离子。 | 复数：Kolloide |
| die Nettoladung | 净电荷 | 正负电荷综合后的剩余电荷。 | 复数：Nettoladungen |
| die Erdkruste | 地壳 | 地球最外层的固体部分；本讲介绍其主要元素。 | 通常单数 |
| der Sauerstoff | 氧 | 元素 O，讲义中地壳质量占比最高的元素。 | 无复数 |
| das Silizium | 硅 | 元素 Si，与氧共同构成许多地壳矿物。 | 无复数 |
| das Chlorophyll | 叶绿素 | 参与吸收光能，使光能进入生命过程的色素。 | 无复数 |
| die Photosynthese | 光合作用 | 利用光能形成有机物的过程，是理解初级生产的基础。 | 通常无复数 |
| der Wasserkreislauf | 水循环 | 水在海洋、大气、陆地等储存部分之间循环；对应 hydrological cycle。 | 复数：Wasserkreisläufe |
| der Niederschlag | 降水 | 由大气到达地表的雨、雪等水分。 | 复数：Niederschläge |
| die Verdunstung | 蒸发 | 液态水转为水蒸气；对应图中 Evaporation。 | 通常无复数 |
| die Transpiration | 蒸腾 | 植物通过叶片等向大气释放水蒸气。 | 通常无复数 |
| die Interzeption | 植被截留 | 降水先被叶片和枝干等拦截；部分水可再次蒸发。 | 通常无复数 |
| die Infiltration | 入渗 | 地表水进入土壤的过程。 | 通常无复数 |
| die Perkolation | 下渗 | 水在土壤或可渗透介质内部继续向下移动。 | 通常无复数 |
| der Oberflächenabfluss | 地表径流 | 未入渗的水沿地表流动。 | 复数：Oberflächenabflüsse |
| der Grundwasserabfluss | 地下水排泄 | 地下水向河流、湖泊或海洋等排出；对应 Groundwater discharge。 | 复数：Grundwasserabflüsse |
| die Bodenfeuchte | 土壤湿度 | 土壤中含水状况，可在短时间内变化。 | 无复数 |
| die Vegetation | 植被 | 某地区植物覆盖的总体。 | 通常无复数 |
| der Minimumfaktor | 限制因子 | 供应不足、从而限制生长的环境因素。 | 复数：Minimumfaktoren |
| semiarid | 半干旱的 | 水分较少但并非完全无雨；本讲用于尼日尔虎斑灌丛案例。 | 形容词 |
| die Regenzeit | 雨季 | 季节性降水较充足的时期。 | 复数：Regenzeiten |
| die Trockenzeit | 旱季 | 季节性降水缺乏的时期。 | 复数：Trockenzeiten |
| die Niederschlagsintensität | 降水强度 | 单位时间内的降水量；过高时可能超过入渗能力。 | 复数：Niederschlagsintensitäten |
| das Relief | 地形起伏 | 地表高低和形态，对水的流动方向有影响。 | 复数：Reliefs |
| das Gefälle | 坡降或坡度 | 地表沿一定方向下降的程度。 | 复数：Gefälle |
| der Oberhang | 上坡部 | 坡面较高的部分；用于解释植被带水分差异。 | 复数：Oberhänge |
| der Unterhang | 下坡部 | 坡面较低的部分；用于解释植被带水分差异。 | 复数：Unterhänge |
| die Selbstorganisation | 自组织 | 多个局部过程相互作用而形成有序空间格局；本讲出现 selbst organisierend。 | 通常无复数 |
| die Skala | 尺度 | 观察过程的空间或时间范围。 | 复数：Skalen |
| die Sukzession | 生态演替 | 生态系统物种组成随时间发生的有方向的变化。 | 复数：Sukzessionen |
| die Artenzusammensetzung | 物种组成 | 群落中有哪些物种及其组合。 | 复数：Artenzusammensetzungen |
| die Störung | 扰动 | 火灾、风倒等改变生态系统状态的事件。 | 复数：Störungen |
| die Pionierpflanze | 先锋植物 | 在裸地或扰动后较早建立的植物。 | 复数：Pionierpflanzen |
| das Klimax-Stadium | 顶极阶段 | 讲义演替模型中，在外部条件稳定时形成的相对稳定阶段。 | 复数：Klimax-Stadien |
| die Verjüngungssukzession | 更新演替 | 由持续更新或灾难性扰动引发的演替。 | 复数：Verjüngungssukzessionen |
| der Windwurf | 风倒 | 树木被风吹倒的扰动。 | 复数：Windwürfe |
| der Standortfaktor | 生境因子 | 影响某处植物生长的环境条件。 | 复数：Standortfaktoren |
| edaphisch | 土壤条件相关的 | 用于描述由土壤条件或其变化引发的影响。 | 形容词 |
| der Treibhauseffekt | 温室效应 | 大气吸收并发射热辐射，使地表及低层大气增暖的机制。 | 复数：Treibhauseffekte |
| die Kaltzeit | 冷期 | 地质气候记录中相对寒冷的时期。 | 复数：Kaltzeiten |
| die Warmzeit | 暖期 | 地质气候记录中相对温暖的时期。 | 复数：Warmzeiten |
| die Wasserwirtschaft | 水资源管理 | 对水的利用、调配和管理。 | 无复数 |
| die Wasserkraft | 水力发电或水能 | 利用水的能量发电。 | 无复数 |
| die erneuerbare Energie | 可再生能源 | 由可持续补充的自然过程提供的能源，如水能和太阳能。 | 常用复数 Energien |
| die Nettoprimärproduktion | 净初级生产 | 初级生产者固定的能量或有机物扣除自身呼吸消耗后的部分。 | 无复数 |
| die menschliche Aneignung von Nettoprimärproduktion | 人类对净初级生产的占用 | 衡量人类活动对生态系统营养级能量流的干预。 | 缩写：HANPP |
| die Stadt-Land-Beziehungen | 城乡关系 | 城市与乡村间的物质、能源和社会经济联系。 | 复数 |
| der menschliche Stoffwechsel | 人类代谢 | 学习译名，对应 Human Metabolism；本讲关注食物、水、能源输入和废弃物输出。 | 通常无复数 |
| die Ökosystemleistung | 生态系统服务 | 生态系统向人类提供的益处；讲义使用 Ökosystemleistungen。 | 复数：Ökosystemleistungen |
| das virtuelle Wasser | 虚拟水 | 生产某种商品所需的水，不是商品实体中实际含有的水。 | 无复数 |
