## 一. 科学是什么

#### 1.1 科学的任务
* Erkenntnisgewinn
* Entwicklung von Begriffen
* Entwicklung von Methoden
* Entwicklung von Theorien
* Anwendung gewonnener Erkenntnis

#### 1.2 科学判断与科学过程的标准
* 判断(Aussagen)：
	* von begrenzter Gültigkeit：有适用范围
	* widerspruchsfrei：内部无矛盾
	* widerlegbar / beweisbar：能够接受检验
* 过程(Vorgehen)：
	* erfahrensorientiert (methodisch)：有方法
	* nachvollziehbar und transparent：步骤可理解、透明
* 结果(Ergebnisse)：
	* Wiederholbar：应考虑重复检验

#### 1.3 Popper的三个重点
* Wissenschaft ist stetige Kritik.：已有知识也必须允许质疑
* Logik macht noch keine Wissenschaft.：推理成立，不保证前提符合现实
* Wissenschaft löst Probleme.：评价理论也要看其解释和解决问题的能力

* Methoden: z.B. Kartierung, Zählung, Messung, Befragung

#### 2.2 从现象到概念：Zeichen - Begriff - Phänomen
* 区分：
	* **Zeichen:** 使用的词或符号
	* **Begriff:** 词所表达的概念与意义
	* **Phänomen:** 所指向的现象或对象

#### 2.3 概念的分类

| Begriff                      | Erläuterung                                                                                                                                             | Beispiel                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| Präskriptive Begriffe(规范性概念) | Sprachsymbole für Wertdimensionen: 表达价值维度                                                                                                               | gut, schlecht, gerecht                                   |
| Deskriptive Begriffe         | Sprachsymbole für Beschreibungen der Wirklichkeit：描述现实对象及特征                                                                                             | Gegenstände, Merkmale, Aspekte                           |
| Operationale Begriffe        | Sprachsymbole für unmittelbar erfahrbare, messbare Eigenschaften：指向可直接经验或测量的属性                                                                          | Haus, Fluss, Wärme                                       |
| Theoretische Begriffe        | Sprachsymbole für abstrakte, komplexe Phänomene, die nicht direkt beobachtbar sind. Sie können über operationale Begriffe definiert werden：抽象、复杂，不能直接观察 | Metropole, Tropen, Kultur, Agglomeration(集聚), Wettbewerb |

#### 2.4 陈述的分类

| Aussage                  | Erläuterung  | Beispiel                                                                                  |
| ------------------------ | ------------ | ----------------------------------------------------------------------------------------- |
| Logische Sätze           | 推理是否成立       | Wenn Heidelberg in Bayern liegt, und Bayern in Italien, dann liegt Heidelberg in Italien. |
| Empirische Sätze         | 基于观察经验       |                                                                                           |
| Deskriptive Sätze        | 是什么          | München liegt an der Isar.                                                                |
| Explikative Sätze(解释性陈述) | 为什么          | Wenn der Luftdruck fällt, regnet es.                                                      |
| Normative Sätze(规范性陈述)   | 应该怎样         | Freie Meinungsäußerung ist ein dringender Grundsatz demokratischen Lebens.                |
| Technologische Sätze     | 为实现目标应采取什么手段 | Um Innovationen zu fördern, müssen Anreize(激励) geschaffen werden.                         |

## 四. 解释与理论

#### 4.1 解释从“为什么”开始
* **Hypothese:** ist eine begründete, überprüfbare Vermutung über einen Zusammenhang oder eine mögliche Erklärung für ein Phänomen.
* **Gleich und Gleich gesellt sich gern.** 物以类聚
	* Menschen fühlen sich am stärksten angezogen von solchen Menschen, deren Charaktereigenschaften den eigenen besonders ähneln. 
* **Gegensätze ziehen sich an.** 异性相吸
	* Menschen fühlen sich am stärksten angezogen von solchen Menschen, deren Charaktereigenschaften von den eigenen abweichen.

#### 4.3 三种理解因果的原则

| Prinzip               | 核心思路                | 主要困难                     |
| --------------------- | ------------------- | ------------------------ |
| Kontrafaktizität(反事实) | 如果 A 没有发生，B 是否还会发生？ | 无法同时观察同一对象在发生／未发生 A 时的结果 |
| Regularität(规律性)      | A 后总是出现 B           | 稳定共现仍可能有其他解释             |
| Probabilität(概率性)     | A 使 B 更可能发生         | 概率关系本身仍不足以排除混杂           |
#### 4.4 理论的三种用法
* Theorie im Gegensatz zur Praxis：与实践相对的理论知识
* Theorie als wissenschaftliches Lehrgebäude：某领域的系统性知识体系
* Theorie im engen Sinne des logischen Empirismus：狭义上具有严格逻辑结构、连接规律与经验现象的理论


## 五. 预测与干预

#### 5.1 解释与预测的区别
* **Erklärung:** 事件已经发生，寻找解释它的规律与条件
* **Prognose:** 利用已有理论和给定条件，推断尚未发生的事件

#### 5.2 Prognose 与 Szenario(情景)

|        | Prognose                                                                        | Szenario                                                                     |
| ------ | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 典型方法   | mathematisch-quantitative Methode 定量模型、模拟                                       | qualitativ-verbales Vorgehen 定性分析                                            |
| 关注点    | Fokussierung einer Entwicklung 较明确的一条发展趋势                                       | Denken in Alternativen 多种可能的发展路径                                             |
| 典型时间尺度 | kurzer Zeithorizont                                                             | langer Zeithorizont                                                          |
| 适用问题   | Vorhersage relativ ‚einfacher‘ Entwicklungen 相对可建模的发展(z.B.Bevölkerungsprognose) | Abschätzung komplexer Entwicklungen 复杂、开放、不确定的发展(z.B.politische Weltordnung) |

#### 5.3 Future cone: 未来锥
* möglich: 可能的未来
* plausibel: 具有合理依据的未来
* wahrscheinlich:较可能发生的未来
* bevorzugt: 希望实现的未来![[截屏2026-11-09 16.17.17.png]]

#### 5.4 四种科学实践的对应关系

| Wissenschaftliche Praxis | Leitfrage                                      | Zentrale Schwierigkeit                                                                 |
| ------------------------ | ---------------------------------------------- | -------------------------------------------------------------------------------------- |
| Beobachtung              | Was ist der Fall? 事实是什么                        | Selektivität, Messung und Klassifikation, Vorwissen, Priming                           |
| Erklärung                | Warum ist etwas der Fall? 为什么如此                | Kausalidentifikation und alternative Mechanismen                                       |
| Prognose                 | Was wird der Fall sein? 未来怎样                   | Unsicherheit, Modellübertragbarkeit(模型适用范围) und Veränderungen                          |
| Gestaltung(干预/设计)        | Was würde geschehen, wenn wir handeln? 采取行动会怎样 | Kontrafaktische Intervention(反事实), Rückkopplungen(反馈) und unerwünschte Wirkungen(意外后果) |
